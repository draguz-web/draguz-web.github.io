# Draguz Web

Página principal de Draguz Web: páginas web para negocios.

- `index.html`: página principal (trabajos, paquetes, proceso, preguntas).
- `cotiza/`: formulario para que el cliente cuente qué página necesita y lo mande por WhatsApp.
- `img/`: capturas de los trabajos.

Para poner tu WhatsApp, cambia `const WHATSAPP=""` en `index.html` y en `cotiza/index.html` (52 + 10 dígitos).
